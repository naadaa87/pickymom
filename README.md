# 픽키맘 | 까다롭게 고른 주방·생활·육아용품 기록

직접 써 본 주방·생활·육아용품을 고른 이유와 아쉬운 점까지 적어 두는 개인 홈페이지예요. 『픽키맘 홈페이지 종합기획서 3.0』을 바탕으로 만들었어요.

- **픽키 리뷰**: 제품 카드(픽키 카드), 깐깐 체크(○△✕와 한 줄 이유), 세 가지 판정(다시 산다·고민 중·안 산다), 써 본 기간(첫인상·한 달 뒤·여섯 달 뒤), 아쉬운 점, 다시 쓰는 후기. 여러 물건을 비교한 글도 쓸 수 있어요.
- **살림 일기**: 짧은 글과 사진
- **준비물 목록**: 산 것·미룬 것·안 산 것·고르는 중으로 나눈 체크리스트. 방문자의 체크는 그 사람 브라우저에만 남고, 인쇄할 수 있어요.
- **소개, 제휴 링크 안내, 개인정보 처리방침**
- **관리 화면(/admin)**: 휴대폰으로 글쓰기, 사진 올리기(자동으로 줄이고 촬영 위치 정보를 지움), 미리보기, 올리기 전 점검표, 예약 공개, 다시 쓸 후기 알림, 준비물 목록 편집, 링크 점검, 클릭 수, 백업
- 사이트 지도(`/sitemap.xml`), RSS(`/feed.xml`), 공유 미리보기, 검색용 정보

글은 Cloudflare D1 데이터베이스에 저장되고, 화면은 Cloudflare Pages Functions가 그때그때 만들어요. 따로 빌드할 것이 없어요.

## 1. Cloudflare에 배포하기

모두 브라우저에서 할 수 있어요. 터미널은 필요 없어요.

### 1-1. Pages 프로젝트 만들기

1. [Cloudflare 대시보드](https://dash.cloudflare.com)에 들어가 왼쪽 메뉴에서 **Workers & Pages**를 눌러요.
2. **Create**(만들기)를 누르고 **Pages** 탭에서 **Connect to Git**(Git에 연결)을 골라요.
   Pages 탭이 보이지 않으면 화면 아래쪽 ‘Looking to deploy Pages?’ 링크를 누르세요.
3. GitHub 계정을 연결하고 이 저장소(`naadaa87/pickymom`)를 골라요.
4. 빌드 설정을 이렇게 넣어요.

   | 항목 | 값 |
   | --- | --- |
   | 프로젝트 이름 | `pickymom` (사이트 주소가 `pickymom.pages.dev`가 돼요) |
   | 프로덕션 브랜치 | `main` |
   | 프레임워크 프리셋 | None (없음) |
   | 빌드 명령 | 비워 둬요 (비워 둘 수 없으면 `exit 0`) |
   | 빌드 출력 디렉터리 | `public` |

5. **Save and Deploy**(저장 및 배포)를 눌러요. 1~2분 뒤 사이트가 만들어지는데, 아직은 ‘홈페이지를 준비하고 있어요’ 화면이 나와요. 다음 단계에서 데이터베이스를 연결하면 열려요.

> 프로젝트 이름을 `pickymom`으로 쓸 수 없어 다른 이름을 썼다면, 이 저장소의 `site.config.json`에서 `siteUrl`을 실제 주소로 바꿔 주세요(3장).

### 1-2. 데이터베이스(D1) 만들고 연결하기 (필수)

1. 대시보드 왼쪽 메뉴에서 **Storage & Databases → D1 SQL Database**(또는 **Workers & Pages → D1**)로 가서 **Create**(만들기)를 눌러요. 이름은 `pickymom-db`로 해요.
2. **Workers & Pages → pickymom → Settings(설정) → Bindings(바인딩)**에서 **Add**(추가) → **D1 database**를 골라요.
   - Variable name(변수 이름): `DB` (대문자 그대로)
   - D1 database: `pickymom-db`

표(테이블)는 처음 접속할 때 저절로 만들어져요. SQL을 따로 실행하지 않아도 돼요.

### 1-3. 관리 화면 비밀번호 넣기 (필수)

같은 설정 화면의 **Variables and Secrets**(변수 및 비밀)에서 **Add**(추가)를 눌러요.

- Type(유형): **Secret**(비밀)
- Variable name: `ADMIN_PASSWORD`
- Value: 관리 화면에 쓸 비밀번호 (길고 남이 짐작하기 어렵게. 글 쓰는 사람과 지원하는 사람이 함께 써요)

### 1-4. 다시 배포하고 확인하기

1. 설정은 다음 배포부터 적용돼요. **Deployments**(배포) 탭에서 가장 최근 배포 오른쪽 메뉴(…)를 눌러 **Retry deployment**(배포 다시 시도)를 해 주세요.
2. 브라우저에서 `https://pickymom.pages.dev/api/health`를 열어 `"db":true,"admin":true`가 보이면 끝이에요.
3. `https://pickymom.pages.dev/admin/`에서 비밀번호로 들어가 보세요.

### 1-5. 방문 통계 켜기 (선택)

**Workers & Pages → pickymom → Metrics**(지표)에서 **Web Analytics**를 켜면 방문자 수를 볼 수 있어요. 쿠키를 쓰지 않는 방식이라 개인정보 처리방침과도 맞아요.

### 1-6. 사진을 R2에 저장하기 (선택)

연결하지 않아도 사진은 D1에 저장되고 잘 보여요. 사진이 많이 쌓이면(수천 장) 그때 옮겨도 돼요.

1. **R2 Object Storage**에서 버킷을 만들어요. 이름은 `pickymom-images`. R2를 처음 켤 때 결제 정보를 요구할 수 있어요.
2. Pages 설정의 **Bindings**에서 **Add → R2 bucket**, 변수 이름 `IMAGES`, 버킷 `pickymom-images`.
3. 다시 배포해요. 그 뒤로 올리는 사진은 R2에 저장되고, 예전 사진은 D1에서 그대로 보여요.

## 2. 글쓰기

### 처음 들어가면

- 휴대폰 브라우저로 `/admin/`에 들어가 로그인해요. ‘이 기기에서 30일 동안 로그인 유지’를 켜 두면 편해요.
- 휴대폰 홈 화면에 추가해 두면 앱처럼 열 수 있어요. (아이폰: 공유 → 홈 화면에 추가, 안드로이드: 메뉴 → 홈 화면에 추가)
- 화면이 어떻게 보이는지 먼저 보고 싶으면 **더 보기 → 설정과 도움말 → 예시 글 넣기**를 눌러요. 초안 상태로 들어가서 공개되지 않아요. 글을 열어 **미리보기**로 확인한 뒤 지우면 돼요.

### 리뷰 한 편 쓰는 순서

1. **글 → ＋ 리뷰 쓰기**
2. 제목, 분야(주방·생활·육아), 품목, 대가 관계(내 돈으로 샀다 / 제공받았다)
3. 대표 사진 (휴대폰에서 고르면 긴 변 1,600px로 줄이고 촬영 위치 정보를 지운 뒤 올라가요)
4. **제품 카드**: 이름, 산 날, 값, 산 곳, 판정, 써 본 기간, 지금도 쓰는지, 한 줄 평, 깐깐 체크
   - 산 날을 넣으면 알맞은 써 본 기간을 알려 줘요.
   - 깐깐 체크는 ○△✕를 고른 항목만 공개 화면에 보여요. 같은 표시를 다시 누르면 고른 것이 풀려요.
   - 여러 물건을 비교한 글이면 **＋ 제품 추가**. 공개 화면 맨 위에 한눈에 보는 목록이 생겨요.
5. **본문**: 소제목·굵게·목록·사진 넣기 단추를 쓰면 돼요.
6. **아쉬운 점** (꼭 적어야 공개돼요)
7. **올리기 전 점검표**를 모두 체크하고 **공개하기** 또는 **예약**

### 저절로 지켜지는 것

기획서의 원칙 가운데 빠뜨리기 쉬운 것은 화면과 서버가 막아 줘요.

| 원칙 | 어떻게 지켜지나 |
| --- | --- |
| 대가 관계는 글머리에 | ‘내돈내산’ 또는 ‘제공받음’이 제목 바로 아래 자동으로 붙어요. 구매 링크가 있으면 ‘수수료 링크’와 쿠팡 파트너스 문구도 함께 붙어요 |
| 구매 링크는 ‘다시 산다’에만 | 판정이 ‘다시 산다’가 아니거나 ‘첫인상’ 글이면 링크를 저장할 수 없어요 |
| 링크는 글 하나에 둘까지 | 셋 이상이면 저장되지 않아요 |
| 링크는 제품 카드에만 | 본문이나 후기에 쿠팡 주소를 넣으면 저장되지 않아요 |
| 아쉬운 점도 쓴다 | 아쉬운 점이 비어 있으면 공개되지 않아요 |
| 올리기 전 점검 | 점검표를 모두 체크해야 공개·예약할 수 있어요 |
| 시험한 것처럼 쓰지 않기 | ‘검증’, ‘테스트’, ‘최고’, ‘면역’ 같은 말이 들어가면 확인해 보라고 알려 줘요 |
| 사진 속 위치 정보 | 올릴 때 휴대폰에서 지워져요 |
| 구매 링크에 rel="sponsored" | 검색엔진에 광고 링크라고 알려 주는 표시가 자동으로 붙어요 |

### 다시 쓰는 후기

산 날에서 한 달, 여섯 달이 된 물건은 **다시 쓰기** 탭에 나타나요. 세 줄이면 충분하고, ‘이번엔 건너뛰기’를 눌러도 돼요. 덧붙이면 써 본 기간이 올라가고, 판정이 바뀌었으면 함께 고칠 수 있어요. 판정을 ‘다시 산다’가 아닌 것으로 바꾸면 구매 링크는 저절로 내려가요.

### 준비물 목록

**준비물 → ＋ 새 목록**. 묶음(예: 수유), 이름, 상태(산 것·미룬 것·안 산 것·고르는 중), 메모, 이어 줄 글을 넣고 ‘공개’로 저장해요.

### 더 보기

- **링크 점검**: 한 달에 한 번 링크를 열어 보고 ‘열려요/안 열려요’를 눌러요. ‘안 열려요’로 표시한 링크는 공개 화면에서 숨겨져요.
- **숫자**: 제품별 구매 링크 클릭 수. 쓰는 사람이 신경 쓰지 않도록 기본으로 숨겨 두었어요. **설정과 도움말 → ‘더 보기’에 숫자 메뉴 보이기**를 지원하는 쪽 기기에서만 켜 주세요. 같은 화면의 ‘이 기기에서 누른 구매 링크는 세지 않기’도 켜 두면 좋아요.
- **백업**: 한 달에 한 번 **백업 내려받기**로 받아 보관해요. 글, 제품 카드, 후기, 목록이 들어 있어요. 사진 원본은 휴대폰 사진첩에 있어요.

## 3. 사이트 설정 (`site.config.json`)

GitHub에서 파일을 열고 연필 모양(Edit)을 눌러 고친 뒤 **Commit changes**를 누르면 1~2분 뒤 사이트에 반영돼요.

| 항목 | 뜻 |
| --- | --- |
| `siteName`, `tagline` | 이름(픽키맘)과 소개 문구 |
| `siteTitle`, `description`, `keywords` | 첫 화면 제목, 검색 설명, 검색어(피키맘, pickymom 포함) |
| `siteUrl` | 실제 사이트 주소. 도메인을 연결하면 꼭 바꿔 주세요. 검색용 대표 주소와 사이트 지도가 여기서 정해져요 |
| `instagram` | 인스타그램을 하게 되면 `picky.mom`처럼 넣어요. 바닥에 @picky.mom 링크가 생겨요 (비워 두면 안 보여요) |
| `contactEmail` | 소개·개인정보 처리방침·바닥에 보일 문의 메일. 전용 메일을 넣어 주세요 (비워 두면 안 보여요) |
| `naverSiteVerification`, `googleSiteVerification` | 네이버 서치어드바이저, 구글 서치 콘솔의 소유 확인 값 |
| `policyDate` | 개인정보 처리방침 시행일 |

## 4. 도메인 연결과 검색 등록

1. 도메인은 법인 명의로 등록해요(기획서 10장).
2. Pages 프로젝트의 **Custom domains**(사용자 지정 도메인)에서 도메인을 추가하고, `site.config.json`의 `siteUrl`을 새 주소로 바꿔요.
3. 네이버 서치어드바이저: 사이트 등록 → 소유 확인에서 ‘HTML 태그’를 골라 `content="..."` 안의 값을 `naverSiteVerification`에 넣고 커밋한 뒤 확인을 눌러요. 그다음 **요청 → 사이트맵 제출**에 `https://(주소)/sitemap.xml`, **RSS 제출**에 `https://(주소)/feed.xml`을 넣어요.
4. 구글 서치 콘솔: URL 접두어 방식 → HTML 태그 값을 `googleSiteVerification`에 넣고 확인 → **Sitemaps**에 `sitemap.xml` 제출.

## 5. 쿠팡 파트너스

- **법인 유형(세금계산서 발행)**으로 가입하고, 활동 채널에 이 홈페이지 주소를 등록해요(기획서 10.3).
- 쿠팡 파트너스 → 링크 생성에서 만든 링크(`https://link.coupang.com/a/...`)를 제품 카드의 **구매 링크** 칸에 붙여 넣어요.
- 링크는 쿠팡 주소 그대로 걸려요. 홈페이지를 거쳐 가는 주소를 만들지 않고, 누를 때 클릭 수만 따로 세요.
- 대가성 문구는 글머리, 구매 단추 아래, 사이트 바닥, 제휴 링크 안내 페이지에 들어가 있어요. 지우지 마세요.

## 7. 알아 둘 것

- 공개 화면은 빠르게 보이도록 최대 10분 동안 저장해 두었다가 보여 줘요. 글을 고치면 바로 새로 만들어지고, **예약한 글은 예약 시각부터 10분 안에** 나타나요.
- 사진은 휴대폰에서 줄인 뒤 올라가서 한 장에 보통 수백 KB예요. 원본은 올라가지 않아요.
- Cloudflare 무료 요금제 안에서 운영할 수 있어요. D1은 하루 읽기·쓰기 상한이 있는데, 개인 홈페이지 규모에서는 넘기 어려워요. 요금과 상한은 바뀔 수 있으니 Cloudflare 공식 문서에서 가끔 확인해 주세요.
- 관리 화면 비밀번호를 15분 안에 8번 틀리면 잠시 막혀요. `ADMIN_PASSWORD`를 바꾸면 모든 기기에서 다시 로그인해야 해요.

## 8. 폴더 구조

```
functions/[[path]].js   모든 동적 주소의 입구 (공개 화면, /api, /img, 사이트 지도)
server/
  pages.js              공개 화면 (첫 화면, 리뷰, 일기, 준비물, 소개, 정책)
  layout.js             화면 틀, 검색용 정보
  admin.js              관리 화면 API (저장, 검사, 예약, 후기, 목록, 링크, 숫자, 백업)
  data.js               공개 화면용 데이터 읽기
```
